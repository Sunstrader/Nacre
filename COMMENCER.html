Une autre rive.

Explorez une ville engloutie, rencontrez ses habitants et décidez du sort de ses souvenirs.

Commencer à jouer →

À votre rythme

  • Choisissez Aventure pour l’équilibre normal, ou Histoire pour des confrontations plus faciles.
  • Examinez les repères du décor ou les boutons dans la liste Interactions.
  • Chaque choix majeur reçoit une réaction propre et laisse une trace dans le carnet.
  • Activez Voir l’écho pour révéler les souvenirs cachés.
  • Au camp, le repos restaure gratuitement vos forces.
  • En combat, l’intention adverse annonce ce qui vient. Chaque confrontation a aussi une issue pacifique.

Garder votre traversée

Le jeu se sauvegarde automatiquement dans le navigateur. Dans Sauvegardes, exportez un JSON avant de changer d’appareil ou de déplacer le fichier. Trois emplacements permettent de garder différentes étapes.

Les sons

Les effets sont intégrés. La musique est à ajouter avec vos propres fichiers dans les réglages. La lecture vocale optionnelle utilise les voix françaises de votre appareil ; aucun doublage préenregistré n’est fourni.
